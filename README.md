# 離れ（Hanare）— 副業オペレーション・コンソール

副業の制作・発信・収益導線を一枚で見るための管理画面。制作見本です。
**表示しているデータはすべて架空**で、実在の個人・団体とは関係ありません。

制作：ねぎみそとうふ

---

## なぜこの画面を作ったか

管理画面は、業種が違っても同じ顔になりがちです。角丸のカードに影を付け、KPIを4枚並べ、
折れ線とドーナツを置き、下に表を敷く。中身を入れ替えても同じ画面に見えます。

この画面では、そこを3点で外しました。

1. **角丸2px・影なし。** 階層は1pxの罫線と地色の差だけで作っています
2. **見出しは明朝。** 本文のゴシックと表情を変え、情報の格を立てます
3. **この仕事にしかない部品を5つ作りました**（下記）

## 5つの部品

| 部品 | 何を見る道具か | 汎用部品との違い |
|---|---|---|
| **縁側バー** | 今週、手を動かせる枠の総量 | 予定を「置く」カレンダーではなく、置ける「量」を面積で見る |
| **公開レール** | 手元 → 出していない → 公開中 | 表の状態列では気づけない「完成しているのに出していない」が見える |
| **導線図** | 発信から報酬までの接続 | 数字の前に、そもそも線が繋がっているかを見る |
| **栓** | 1件の詰まりが下流いくつを止めているか | 優先度の高中低を使わず、影響範囲の広さをそのまま棒の長さにする |
| **行灯** | 期限の迫りかた | 赤ベタで警告せず、隅からにじむ灯りで気づかせる |

## 使いかた

`index.html` をブラウザで開くだけです。ビルドもサーバーも要りません。

- 右上の **「データあり／空の状態」** で、空のときの画面に切り替わります
- 右上の **◐** で昼と夜が入れ替わります（夜に使う道具なので、夜を同格で設計しています）
- <kbd>/</kbd> で検索、<kbd>Esc</kbd> で解除
- 状態を変えると、5秒間は取り消せます

## 作りの方針

- **外部通信をしません。** CDN・解析・外部フォントの取得はありません。オフラインで動きます
- **個人データを持ちません。** 保存するのは昼夜の別だけです
- **削除操作を置いていません。** 取り消せない操作をこの画面から行えないようにしています
- **権限を画面に明示しています**（閲覧／編集／管理の3段。この見本は編集権限）
- JavaScriptを切っても、データはHTMLに書き出してあるため全部読めます
- コントラスト比4.5:1以上、`:focus-visible` 常時表示、`prefers-reduced-motion` 対応、印刷用の指定あり

## ファイル

```
hanare-console/
├─ index.html     構造
├─ styles.css     [A]骨格レイヤー ／ [B]意匠レイヤー の2層に分割
├─ script.js      表示の切替・絞り込み・取り消し
├─ assets/
│  └─ favicon.svg
└─ README.md
```

`styles.css` はファイル冒頭で2層に区切ってあります。意匠の仕上げは **[B] 意匠レイヤー** だけを対象にし、
**[A] 骨格レイヤー**（変数名・レイアウト・アクセシビリティ）は変更しません。
